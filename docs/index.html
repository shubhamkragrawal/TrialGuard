The product in one minute

A second reviewer for trial operations.

TrialGuard does not predict whether a trial will succeed. It helps teams inspect operational assumptions by connecting a current trial to relevant public precedents and showing exactly where each claim came from.

    ⌕

    Load a small, explicit set of public trial fields and a bounded comparison cohort.

    Find comparable stopped trials and retain the exact registry passage behind each precedent.

  3. 03

    Check citation membership, passage support, numeric facts, and prohibited language.

  4. 04

    Hand off

    Release questions—not recommendations—to a qualified human reviewer.

Why the guardrails matter

Useful only when uncertainty stays visible.

A

Model roles are bounded

Evidence, coordination, and challenge roles organize the brief; fixed code controls what is released.

B

Unsupported content is withheld

A missing citation, mismatched number, or unsafe claim can block the affected output.

C

The person remains responsible

Registry similarity is not causation, and a generated question is not a protocol decision.

Intended use

A bounded decision-support demonstration.

TrialGuard is designed for a clinical-operations or trial-feasibility reviewer at a sponsor or CRO. It organizes selected public registry evidence into an inspectable brief. The qualified user remains responsible for every protocol and operational decision.

✓

What it demonstrates

  • Retrieval from allowlisted public registry fields
  • Transparent, bounded comparison logic
  • Evidence-linked operational review questions
  • Deterministic gates around generated output
  • Visible uncertainty, limitations, and source links
×

What it does not do

  • Predict trial termination or individual outcomes
  • Recommend treatment, protocol, or design changes
  • Issue go/no-go, clinical, regulatory, or legal advice
  • Process patient data or confidential protocols
  • Replace clinical, regulatory, or operational judgment
AWS

Hosting status

Why this static showcase exists

The intended deployment uses AWS in us-east-1, with Bedrock for bounded model roles and a managed web service for the application. The current workshop role allows model experimentation but denies the hosting services needed to publish the live app. This GitHub Pages site is the reviewed static fallback; it makes no live Bedrock or ClinicalTrials.gov requests.
